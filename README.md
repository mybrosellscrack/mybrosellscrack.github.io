# Духовный дневник

Статический сайт с блогом и отдельной страницей «Индекс душевного здоровья». Работает полностью в браузере — без сервера, базы данных и регистрации.

**Исходники:** [github.com/mybrosellscrack/mybrosellscrack.github.io](https://github.com/mybrosellscrack/mybrosellscrack.github.io)

## Страницы

- **`index.html`** — главная страница блога со списком статей и серий.
- **`health.html`** — отдельная страница «Индекс душевного здоровья».
- **`blog/*.html`** — статьи и страницы разборов.
- **`blog/book.html`** — оглавление прямого разбора книги в 9 частях.
- **`blog/boosty.html`** — краткая Boosty-серия из 5 частей.
- **`blog/series.html`** — архивная обобщённая серия из 8 частей.
- **`styles.css`**, **`blog.css`**, **`blog/review.css`** — стили сайта и страниц разборов.
- **`app.js`** — рендеринг блога и логика индекса.

## Индекс душевного здоровья

Триединая шкала (Чувства / Воля / Желания) — 30 вопросов, по 10 на каждый блок.

- **0–7** — Зелёный: гармония.
- **8–15** — Жёлтый: умеренные трудности.
- **16–23** — Оранжевый: выраженные проблемы.
- **24–30** — Красный: тяжёлое состояние.

Данные теста сохраняются только в `localStorage` браузера. На сервер ничего не передаётся. При очистке кэша результаты будут потеряны. История замеров — до 60 записей.

## Технологии

- HTML5 + CSS3 (Custom Properties, Flexbox, Grid, `backdrop-filter`).
- Vanilla JavaScript (ES6+, `localStorage`, делегирование событий).
- Адаптивная вёрстка.

## Локальный запуск

Сайт статический. Достаточно открыть `index.html` в браузере или раздать папку через любой HTTP-сервер:

```bash
python -m http.server 8000
```
